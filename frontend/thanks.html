algosee started as a small idea: watch sorting and pathfinding algorithms think, step by step. Third Space gave us the push and the reason to actually finish it.

what we built

algosee is a website that animates algorithms. Sort bars swap in front of you, a pathfinder floods a grid, and you can run two algorithms next to each other to see which one wins.

what we learned

We learned how to split a project between two people, how to keep animations in sync with the algorithm underneath, and how much cleaner code gets once you let someone else review it.
